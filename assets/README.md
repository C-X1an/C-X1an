# Project-map artwork

Original artwork generated specifically for Chong Xian’s engineering portfolio with Codex’s built-in image generation tool. The service did not expose its exact model identifier.

The hero gives each featured project a distinct visual motif: RelayFence’s permission boundary, BranchHarbor’s branching state and recovery loop, and WattMosaic’s incomplete sensor patterns resolving into a signal. These are artistic metaphors for separate projects; they are not an architecture diagram, evaluation results or a claim that the projects form one deployed pipeline.

A dark editorial composition and coordinating mineral-ivory variant are served through a theme-aware picture element. The project links and full explanation remain accessible as normal README text. Originals were preserved; final assets were resized to 1536 × 512 and optimized as WebP. No fake metrics, badge artwork or professional credentials were added.

Mobile uses separately generated 768 × 768 compositions with vertically arranged motifs and larger labels. The wide artwork is not merely shrunk or cropped on phones.
